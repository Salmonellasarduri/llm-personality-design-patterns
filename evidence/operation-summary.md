# Source-System Operation Summary

Snapshot date: **2026-07-14**

This file contains aggregate, sanitized evidence from the private source system
that produced these patterns. It contains no private conversation text.

## What the snapshot supports

- The source system has operated continuously for 4+ months.
- The original 14-day extraction included 1,226 experience records.
- The newer integrity and assurance paths have reached fixture-tested, staged,
  or operational states described in the main README.
- Recall-only and Dialogue Resilience paths emitted observable runtime events.
- Personality-facing changes are routinely checked with fresh-response
  behavioral validation.

## What it does not support

- causal superiority over another architecture;
- generalization beyond one source system;
- a complete failure-rate denominator for behavioral validation;
- effectiveness of Dialogue Resilience under sustained multi-turn pressure;
- a runtime success rate for Memory Mis-attribution Guard;
- claims of consciousness, sentience, or human-equivalent personality.

## Metrics

Machine-readable values and caveats are in
[`aggregate-metrics.json`](aggregate-metrics.json).

A Recall-only lifecycle row is one typed write, rejection, step result, or
summary emitted by its nightly lifecycle. It measures pipeline activity; the 54
surface events are the user-facing projection count.

## Evidence discipline

`operational` means an enabled path produced observable evidence. It is not a
quality grade. Missing durable capture is reported as unavailable rather than
as zero. Qualitative examples remain private unless they can be safely
abstracted into fixtures.
